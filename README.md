# Mery Terapias

Static personal therapy website.

## GitHub Pages

This project does not need a build step. In the GitHub repository settings, enable
GitHub Pages and choose **Deploy from a branch**, then select the `main` branch
and `/ (root)` folder.

The site is available at:

- Project Pages: `https://davecameron77.github.io/Mery/`
- Custom-domain Pages: set the Pages custom-domain setting and update DNS as
  described by GitHub.
